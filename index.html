StarNet Uploader

A private publishing tool for the YouTube channel Redacted After Dark. It appears on Google's sign-in screen as StarNet.

What it does

StarNet Uploader is a small desktop application run by its operator, Timothy Britt. It uploads short videos that the operator has produced to the operator's own YouTube channel, using the YouTube Data API. It sets each video's title, description, tags, privacy status and scheduled publish time from the operator's own post queue.

Who it is for

The application is used only by its operator to manage his own channel. It is not offered to the public and does not access any other person's YouTube account.

Google and YouTube data

The application requests two permissions: youtube.upload, to upload videos and set their details, and youtube.readonly, used only to read the connected channel's name and confirm each upload's status. It uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Details of how data is handled are in the Privacy Policy below.
